    เช็กลิสต์ให้ติด Google และ AI

    • ยืนยันเว็บใน Google Search Console แล้วส่ง sitemap.xml
    • เพิ่มเว็บใน Bing Webmaster Tools (ChatGPT Search และ Copilot ใช้ข้อมูลจาก Bing) นำเข้าจาก Search Console ได้ในคลิกเดียว
    • มี robots.txt ที่อนุญาต GPTBot, OAI-SearchBot, ClaudeBot, PerplexityBot และมี llms.txt สรุปเว็บให้ AI อ่าน
    • ทุกหน้ามี title, description และข้อความจริงให้อ่าน (ไม่ใช่แค่เกมใน canvas) พร้อม FAQ ที่ตอบคำถามที่คนค้นจริง
    • ลงลิงก์เกมในที่ที่ AI ชอบอ้างอิง เช่น itch.io, Reddit, Pantip, YouTube และกลุ่ม Facebook
    • ดูแท็บนี้ทุกสัปดาห์: Organic Search และ AI ควรค่อย ๆ เพิ่มขึ้น และ LCP บนมือถือควรต่ำกว่า 2.5 วินาที
